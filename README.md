🛒 SHOPA - Multi Vendor E-Commerce Web Application

SHOPA is a modern and fully responsive Multi-Vendor E-Commerce Web Application developed using **Python Flask** and **SQLite**. The platform allows customers to browse and purchase products, vendors to manage their own stores and products, and administrators to control the entire marketplace through a professional admin dashboard.

🚀 Features

👤 Customer Module
- User Registration & Login
- Secure Password Hashing
- Product Search & Categories
- Shopping Cart
- Wishlist
- Checkout & Order Placement
- Order Tracking
- Invoice PDF Download
- User Profile Management
- Delivery Address Management

🏪 Vendor Module
- Vendor Registration & Login
- Vendor Dashboard
- Add / Edit / Delete Products
- Product Image Upload
- Manage Orders
- Earnings Dashboard
- Sales Reports
- Vendor Profile
- Vendor Settings

🛠 Admin Module
- Admin Dashboard
- Category Management
- Product Management
- User Management
- Vendor Approval System
- Order Management
- Contact Message Management
- Notification System
- Settings Panel
